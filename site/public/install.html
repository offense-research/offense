02 / REVIEW. MERGE. AUDIT.

A small diff.
A clear starting point.

.github/workflows/offense.yml
  • Runs on pull requests. Also run it manually from the Actions tab after merging.
  • Reads npm and pnpm lockfiles. Does not install your app, execute its scripts, edit code or post comments.
  • Leaves evidence, not surprise fixes. Download scan.json and remediation.md from the run. Advisories are report-only; coverage warnings and scan errors fail the check.
  • Pinned and read-only. Offense and Actions are commit-pinned. The workflow requests only contents: read.
Before you merge

Dependency names and versions go to OSV/npm. Reports stay in GitHub Actions artifacts for 7 days and may contain sensitive details. GitHub Actions usage limits and charges still apply. This is a dependency check, not the full scanner catalog.

Prefer to add the file yourself?
